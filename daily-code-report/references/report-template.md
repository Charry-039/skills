# 日报输出模板

## 默认格式

```markdown
## 工作日报 — {日期}

**作者：** {作者名}
**日期：** {日期}

### 功能模块

1. **{模块 A}**：{不超过 100 字的描述}。
2. **{模块 B}**：{不超过 100 字的描述}。

### 其他

- {非代码工作，可选}
```

## concise 模式

```markdown
## 日报 — {日期}

**作者：** {作者名}

- {模块 A}：{不超过 50 字}。
- {模块 B}：{不超过 50 字}。
```

## 字段说明

| 字段 | 要求 |
|------|------|
| 日期 | `YYYY-MM-DD` |
| 作者 | git user.name 或 `--author` 指定值 |
| 功能模块 | 按业务领域聚合，1 个模块 1 段 |
| 描述 | 说明"做了什么"和"达成什么效果"，避免罗列文件名 |
| 其他 | 可选，仅当存在非代码工作且用户需要时列出 |

## 文风要求

- 严谨简短，不用口语化表达
- 不过度使用技术名词
- 不列举过细功能点
- 使用第三人称或省略主语的客观叙述
